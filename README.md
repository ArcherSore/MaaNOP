## ✨ 核心亮点

- **独立桌面后台挂机**：在独立 Windows 桌面会话中运行游戏与脚本，不持续占用日常使用的鼠标、键盘和窗口焦点。
- **无需调整分辨率和缩放**：不必为了运行脚本手动修改 Windows 显示分辨率或缩放比例。
- **练小号与一键日常**：支持批量练小号、领取资源，木叶购物节还能给大号送字。大号也可以一键完成日常任务，省时省心。

## 📋 功能一览

- **练小号**：批量注册并练级、批量领取资源、木叶购物节自动送字。
- **日常任务**：进入游戏、游戏托管、通缉任务、押镖、竞技场、排位战、竞技场一键六道、生存演习、丰饶之间、忍者测验、福利大厅与月卡、修行录领取、杂货铺购物、试试手气。
- **周常任务**：组队副本、强者降临、组织通灵兽、周末活动（拼图）。
- **限时活动**：主题竞技场、任务商人、忍者能力考试等，随版本更新。

## 🚀 开始使用

首次使用请先阅读[用户使用手册](https://github.com/ArcherSore/NarutoAutoGUI/blob/main/docs/USER-GUIDE.md)，按步骤保存 Windows 分身登录密码、配置 QQ 大厅自动登录，再开始任务。

从 [Releases](https://github.com/ArcherSore/MaaNOP/releases/latest) 下载 **`MaaNOP-win-x86_64-*.zip`**，完整解压后运行 `NarutoAutoGUI.exe`。按界面提示准备桌面分身、登录游戏、选择任务，即可开始自动化。

> [!IMPORTANT]
> - 支持 **Windows 10/11 x64**，需要管理员权限。
> - 仅支持《火影忍者 Online》**QQ 游戏大厅**客户端，不支持官方微端、360 游戏大厅等其他客户端。
> - 挂机期间可以隐藏桌面分身，但电脑不能进入睡眠或休眠。

## ❓ 常见问题

<details>
<summary>支持官方微端或 360 游戏大厅吗？</summary>

不支持，目前仅支持 **QQ 游戏大厅** 客户端。
</details>

<details>
<summary>挂机时电脑可以睡眠吗？</summary>

不可以。挂机期间可以隐藏桌面分身，但电脑不能进入睡眠或休眠。
</details>

<details>
<summary>需要先改显示分辨率或缩放吗？</summary>

不需要，脚本运行在独立桌面中，不依赖当前显示设置。
</details>
